# niva-cashier-releases

Канал сборок программы «Niva Касса» — настольной админки кассы бота.

Здесь лежат только бинарники: установщик `Niva-Kassa-Setup-<версия>.exe`,
его `.blockmap` и `latest.yml` для автообновления. Исходники — в основном
репозитории приложения.

Наружу файлы отдаёт Cloudflare Worker `niva-update`:

- `/cashier/download` — установщик, открыт всем;
- `/cashier/latest.yml`, `/cashier/<файл>` — автообновление, только по токену
  сессии Кассы (вход в программе — по разовому коду из бота, команда `/app`).

Публикация: `npm run release:cashier` в репозитории приложения.
